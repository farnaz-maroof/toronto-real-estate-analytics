# Toronto Real Estate Market Intelligence

## Overview

This project explores Toronto-area property listing data to better understand housing market patterns and factors associated with property prices.

The analysis follows a complete data analytics workflow, including data cleaning, exploratory data analysis (EDA), feature engineering, regression modeling, and model evaluation.

## Business Questions

- Which regions have higher and lower property prices?
- How are bedrooms and bathrooms related to property values?
- What factors appear to have the strongest relationship with price?
- Can property prices be estimated using a Linear Regression model?

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Git & GitHub

## Workflow

1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Feature Engineering
4. Linear Regression Modeling
5. Model Evaluation
6. Business Recommendations

## Key Findings

- Property prices vary considerably across regions.
- Bedrooms and bathrooms show a positive relationship with price.
- Location appears to be an important factor associated with property values.
- The available features explain only part of the variation in housing prices.

## Recommendations

- Collect additional property features such as square footage, property type, building age, and lot size.
- Incorporate more detailed neighborhood-level information.
- Use the current Linear Regression model as a baseline for future comparison.
- Evaluate more advanced machine learning models after improving data quality and feature coverage.
